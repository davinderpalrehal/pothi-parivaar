# Publishers

First-class publisher records. Attaching a publisher to a book is optional at this stage.

## Record

- A publisher has a single organization name (not first / middle / last).
- Same name reuses one publisher record.

## Link to a book

- A book may have zero or one publisher.
- A book may have authors, a publisher, both, or neither.
- Magazines with no personal author can still name a publishing house.

## Out of this work

- Required publisher.
- Publisher browse UI.
- ISBN or the author migration creating or attaching publishers.
- Publisher address, imprint hierarchy, or authority IDs.
